# TaskFlow

**TaskFlow** is a modern, premium To-Do List mobile application built with Expo and React Native.

Designed to make daily productivity simple, organized, and enjoyable.

## Features

- Premium mobile-first interface
- Create, edit, and delete tasks
- Mark tasks as completed
- Organize tasks by category and priority
- Today's task overview
- Task completion progress
- Calendar-based task planning
- Persistent local storage
- Smooth animations and transitions
- Responsive Android and iOS layouts

## Technology Stack

- Expo
- React Native
- TypeScript
- Expo Router
- React Native StyleSheet
- AsyncStorage
- React Native Reanimated

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/todo-list.git
```

Navigate into the project:

```bash
cd todo-list
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

## Development

Run on Android:

```bash
npx expo start --android
```

Run on iOS:

```bash
npx expo start --ios
```

## Project Structure

- `app/` - Application screens and navigation
- `src/components/` - Reusable UI components
- `src/constants/` - Application constants and colors
- `src/styles/` - Styling and design system
- `src/hooks/` - Custom React hooks
- `src/types/` - TypeScript definitions
- `src/utils/` - Helper functions
- `assets/` - Images, fonts, and icons
